# Notifex positioning  (updated 2026-09-11)

## Statement
For solo developers who run Claude Code and other agents unattended and keep coming back to find them stuck waiting or guessing, Notifex is the pager and decision inbox that turns any agent's question into a push notification you answer in one tap from anywhere, unlike terminal-mirror apps and push tools, which need something running on your Mac and can only alert you, never ask you and wait.

## The one promise (screenshot 1)
"Leave the desk. Your agent will find you."
Why it stops the scroll: it grants permission to do the thing the audience wants (walk, coffee, couch, bed) and flips the category promise. Every neighbor says "code from anywhere" or "your terminal in your pocket", which still means watching a screen; this says the agent comes to you. It pairs with the lock screen push as the visual, so the headline and the image say the same thing. Subline carries the mechanism: "Push when it needs a decision. One tap to unblock." Runner-up kept as an alternate: "Stop babysitting your terminal." (the audience's own phrase).

## Supporting benefits (each maps to a real screen)
1. The agent asks a real question with real options and you tap one. Screen: Thread with a pending single-select question card ("Ship v1.0.1 to TestFlight?" with 2 or 3 options and a free-text composer).
2. It finds you wherever you are. Screen: lock screen push from Notifex with the question title, phone locked.
3. It waits for you, then keeps going. Screen: the same thread after answering: answered card with your chip, and the agent's follow-up bubble "Uploading build 42 to TestFlight" plus a "Done" message.
4. Nothing to run on your Mac. Screen: the Connect step with the MCP JSON card, one entry, a URL and a key.
5. Batches and follow-ups keep decisions in one thread, not a pile of pings. Screen: batch card "1 of 3" pager in a thread.
6. One inbox per project, and a team can answer too. Screen: Inbox with several realistic threads and the project switcher showing "Mobile app", "Data pipeline", "Client site".
7. Works with any MCP agent. Screen: Inbox rows from different agent names (Claude Code, Codex, deploy-bot) or the credentials card labeled "Coding agents".

## Tone
Is: calm, precise, developer-honest. Never: hype, cute, salesy. Banned words: seamless, powerful, supercharge, revolutionary, effortless, AI-powered, unleash, game-changer, 10x. No exclamation marks. No emoji. Sentence case.
